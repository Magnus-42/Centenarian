## 约定

- 「口」= 一个 100G 网口（一个 CMAC 实例）；
- 「通道」= 接收侧分流出的一条路径（每层 = N 条用户通道 + 1 条"未匹配"通道）；
- 「路」= 发送侧的一个用户源；
- 位宽公式里 `MAX` 指全局 `*_MAX` 参数，`N` 指该口实际通道 / 路数。
